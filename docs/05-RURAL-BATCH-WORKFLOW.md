# QUIKOOO Rural Cluster Batch Logistics
**21:00 Cutoff, Overnight Aggregation & Morning Window (05:00–08:00)** | Version 2.0.0 | October 2026

---

### 1. Operational Rationale for Rural Batching
In rural and village cluster zones, low household density makes immediate 15-minute point-to-point delivery economically non-viable. By aggregating daily orders into a single consolidated morning delivery run, QUIKOOO achieves:
- **Vehicle Density:** 1 driver delivers 20–40 aggregated drops across a village cluster in a single run.
- **Predictable Supply:** Merchants receive aggregated wholesale prep manifests the evening before.
- **High Retention:** Village households receive fresh morning essentials (milk, bread, vegetables, medicine) before 08:00 AM.

### 2. Daily Cutoff Timeline (21:00 Asia/Kolkata Standard)

```
06:00 IST             20:00 IST            21:00 IST (HARD CUTOFF)     05:00 - 08:00 IST
  ├─── Open Ordering ───┼── Final Warning ───┼── Batch Locked ───────────────┼── Morning Run ──┤
  │                     │                    │                               │                 │
  ▼                     ▼                    ▼                               ▼                 ▼
Customer Places      App Displays        Orders Set To:                 Driver Dispatched  Customer Drop
Rural Orders         Countdown Banner    SCHEDULED_FOR_NEXT_DAY         Consolidated Route (4-digit OTP)
```

| Phase | Timeline (IST) | System State & Actions | Actor Interactivity |
|---|---|---|---|
| **Ordering Window** | 06:00 – 20:59:59 | Customers add items; marked `SCHEDULED_FOR_NEXT_DAY` | Customer places order; app clearly states next-morning arrival |
| **Cutoff Warning** | 20:00 – 21:00 | Real-time countdown banner displayed across customer app | "Order within 42m for tomorrow morning delivery (05:00–08:00)" |
| **Hard Cutoff Lock** | **Strict 21:00:00** | **Cutoff reached.** Tomorrow's batch is closed and locked | Any order placed at or after 21:00 moves to the *following* day |
| **Batch Aggregation**| 21:05 – 22:00 | System consolidates orders into `BATCH_YYYYMMDD_MORNING` | Local Agent reviews store manifests and assigns batch driver |
| **Vendor Staging** | 22:00 – 04:30 | Merchants pack items in wholesale lots overnight | Merchants review batch summary ticket |
| **Morning Dispatch** | **05:00 – 08:00** | Orders transition: `READY_FOR_MORNING_DISPATCH` → `OUT_FOR_DELIVERY` | Driver executes optimized drop route; completes via OTP |

### 3. Batch Creation Schema & Identifiers
Every rural batch is automatically generated by the batch engine for each rural zone:

```
Batch Identifier Format: BATCH_{YYYYMMDD}_MORNING
Example: BATCH_20261006_MORNING (Zone: zn_kolar_rural_03)
```

| Attribute | Value / Rule | Operational Significance |
|---|---|---|
| `zone_id` | Foreign Key to Rural Zone | Scopes drops strictly within assigned village territory |
| `delivery_date` | `YYYY-MM-DD` (Tomorrow) | Enforces morning run date |
| `window_start` | `05:00:00` Asia/Kolkata | Dispatch departure from cluster hub |
| `window_end` | `08:00:00` Asia/Kolkata | Hard SLA completion deadline |
| `driver_id` | Assigned Rural Fleet Partner | Dedicated driver handling the entire cluster manifest |
| `order_count` | Sum of batch orders | Volume metric for vehicle capacity planning |

### 4. Morning Dispatch Execution Flow
```
04:30 IST: Driver Arrives at Hub / Wholesale Merchants
  │
  ├── Bulk Pickup: Driver scans merchant batch manifests; checks packaged crates
  │
05:00 IST: Morning Route Departure
  │
  ├── Orders Transition: READY_FOR_MORNING_DISPATCH ──> OUT_FOR_DELIVERY
  ├── GPS Broadcast: Route active; customers notified via SMS / WhatsApp / Push
  │
05:15 - 07:45 IST: Sequential Clustered Drop-Offs
  │
  ├── Step 1: Driver arrives at customer doorstep
  ├── Step 2: Customer provides secret 4-digit Delivery OTP
  ├── Step 3: Driver enters OTP into Driver Fleet app
  └── Step 4: System verifies OTP and marks order DELIVERED
```

### 5. Automated Customer Communication Cadence
To maintain customer trust without on-demand tracking anxiety, the platform broadcasts automated updates:

1. **At Checkout:** *"Rural Scheduled Delivery: Your order will be delivered tomorrow morning between 05:00 AM and 08:00 AM."*
2. **At 20:00 IST:** *"Reminder: Rural ordering window closes in 60 minutes for tomorrow morning's fresh dispatch."*
3. **At 21:05 IST:** *"Order Confirmed: Your items are locked into tomorrow morning's dispatch batch (Batch #20261006)."*
4. **At 05:00 IST:** *"Out for Delivery: Driver Ramesh has begun morning deliveries. Your delivery OTP is 4821."*
5. **At Delivery:** *"Delivered: Your order was completed at 06:42 AM. Thank you for choosing Quikooo!"*
